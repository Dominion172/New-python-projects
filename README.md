🧬 DNA Sequence Analyzer (Tkinter GUI)

A simple **Python Tkinter application** for analyzing DNA sequences.  
It allows users to calculate **GC content** and generate the **reverse complement** of a DNA sequence through a clean graphical interface.  


Current Features
- **GC Content Calculation** – Computes the percentage of `G` and `C` bases in a DNA sequence.  
- **Reverse Complement** – Generates the reverse complement sequence.  
- **Graphical User Interface (GUI)** – Built with Tkinter for an interactive experience.  
- **Input Validation** – Ensures only valid DNA characters (`A`, `T`, `G`, `C`) are accepted.  


 Tech Stack
- **Language**: Python 3.x  
- **GUI Framework**: Tkinter (built-in with Python)  

 📂 Project Structure
dna_analyzer/

**Example Usage**

- Enter a DNA sequence in the text box (e.g., ATGCATGC).
- Click Analyze.
- The app will display:
- GC Content (%)
- Reverse Complement of the sequence
